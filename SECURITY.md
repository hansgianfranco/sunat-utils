# Security Policy

## Supported Versions

We actively provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | ✅ Yes             |
| < 1.0.0 | ❌ No              |

---

## Reporting a Vulnerability

We take the security of this project seriously. If you find a vulnerability, please do not open a public issue. Instead, follow these steps:

1.  **Report:** Send an email to **your-email@example.com** with the subject "Security Vulnerability Report".
2.  **Details:** Include a detailed description of the bug, steps to reproduce it, and the potential impact.
3.  **Response:** We will acknowledge your report within 48 hours and provide a timeline for a fix.

---

## Our Process

Once a vulnerability is confirmed:

* We will work on a fix in a private branch.
* A new patched version will be released as soon as possible.
* We will provide credit to the researcher who found it (unless you prefer to remain anonymous).

---

## Disclaimer on Data Privacy

`sunat-utils` is a client-side utility library. It **does not** store, collect, or transmit any sensitive data (like RUC or DNI numbers) to external servers. All processing happens locally in your environment.

**Thank you for helping keep this project secure! 🛡️**
